# Cadetta for Emacs

`cadetta-mode.el` is generated by `editors/generate.py`. It provides
`cadetta-mode` (derived from `prog-mode`, `.cdt` via `auto-mode-alist`),
a `compilation-error-regexp` entry for `cadetta check --format short`, the
command `M-x cadetta-check`, and a flymake backend `cadetta-flymake`.

## Install

use-package:

    (use-package cadetta-mode
      :load-path "/path/to/cadetta/editors/emacs"
      :mode "\\.cdt\\'")

Manual:

    (add-to-list 'load-path "/path/to/cadetta/editors/emacs")
    (require 'cadetta-mode)

Flymake is enabled with `M-x flymake-mode` in a `cadetta-mode` buffer.
