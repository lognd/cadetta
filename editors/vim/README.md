# Cadetta for Vim and Neovim

Files: `ftdetect/` (`*.cdt`), `syntax/cadetta.vim` (generated by
`editors/generate.py`), `ftplugin/` (comment string, indent), and
`compiler/cadetta.vim` (`:make` runs `cadetta check --format short`, results
land in the quickfix list).

## Install

This directory is a plain Vim package root. Pick one:

vim-plug:

    Plug 'lognd/cadetta', { 'rtp': 'editors/vim' }

lazy.nvim:

    { "lognd/cadetta", config = function(plugin)
        vim.opt.rtp:append(plugin.dir .. "/editors/vim")
      end }

Native packpath (Vim 8+, Neovim):

    mkdir -p ~/.vim/pack/cadetta/start
    ln -s /path/to/cadetta/editors/vim ~/.vim/pack/cadetta/start/cadetta

Neovim uses `~/.local/share/nvim/site/pack/cadetta/start/cadetta` instead.

## Use

Primary: start `cadetta lsp` (Neovim `vim.lsp.config`, or vim-lsp / ALE in
Vim); recipes in `editors/README.md`. Diagnostics and formatting only; hover
and code lens are not yet provided (ticket ~0CXQ6EZ).

Fallback: open a `.cdt` file and run `:make` then `:copen`; other bridges
(nvim-lint, efm-langserver) are in `editors/README.md`.

## Limits

The ISO tolerance-class highlight after a quantity is heuristic, and builtin
function names highlight even when used as field names.
