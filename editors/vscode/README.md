# Cadetta for VS Code

Syntax highlighting for `.cdt` files (grammar generated by
`editors/generate.py`), language configuration (`//` comments, brackets,
auto-closing), the `$cadetta` problem matcher and a `cadetta` task type.

## Install (not published)

Build and install a VSIX:

    cd editors/vscode
    npx @vscode/vsce package
    code --install-extension cadetta-0.1.0.vsix

(or Extensions > ... > Install from VSIX). Alternatively copy this directory
to `~/.vscode/extensions/cadetta-0.1.0` and restart VS Code.

## Check task

In `.vscode/tasks.json`:

    {
      "version": "2.0.0",
      "tasks": [
        {
          "label": "cadetta check",
          "type": "shell",
          "command": "cadetta check --format short",
          "problemMatcher": "$cadetta",
          "group": "build"
        }
      ]
    }

The `cadetta` task type (`"type": "cadetta", "command": "check"`) is declared
for task providers; the shell form above works without one.
