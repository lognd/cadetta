# Cadetta for Sublime Text

Files: `Cadetta.sublime-syntax` (generated by `editors/generate.py`),
`Comments.tmPreferences` (`//` toggle-comment), `Cadetta.sublime-build`
(runs `cadetta check --format short`; errors are clickable via `file_regex`).

## Install

Copy this directory's four files into a folder named `Cadetta` under
Sublime's `Packages` directory (Preferences > Browse Packages):

    mkdir -p "$HOME/.config/sublime-text/Packages/Cadetta"
    cp Cadetta.sublime-syntax Comments.tmPreferences Cadetta.sublime-build \
       "$HOME/.config/sublime-text/Packages/Cadetta/"

Open a `.cdt` file; Sublime picks the syntax by the `file_extensions` entry.
Choose Tools > Build System > Cadetta and press Ctrl+B to check.

## Limits

The ISO tolerance-class highlight after a quantity is heuristic, and
builtin function names highlight even when used as field names.
