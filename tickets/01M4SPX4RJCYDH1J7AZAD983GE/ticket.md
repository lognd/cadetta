Open question OQ-3 from the spec. Closes with an ADR in docs/decisions/.

Question: Should packages be able to define new kinds of an existing dimension (e.g. Stress vs Pressure)?

Recommendation: Yes, via `kind Stress = Pressure` declarations in a later version.
