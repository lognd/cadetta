## New diagnostic codes (lints.md is the single catalog; owning docs reference them)
- R008 adapter-unavailable (error for sync, info for check): not installed, wrong platform, version mismatch (closes OQ-7: mismatch is R008, exit 2).
- R009 file-busy (error): document dirty, locked or read-only; refused before any push.
- R010 push-rejected (error): driven or suppressed dimension, equation conflict, unit conflict.

## Geometry (review-3-geometry.md, G1-G12): all accepted, with these specifics
- G1: a ScrewJoint is one part per hole pattern: `part screws: ScrewJoint(..., at = bracket.holes, onto = rail.tapped)`; its count is `count(at)` (G004 when count(onto) differs); it owns `part screw[count(at)]` so BOM and roll-ups count one screw per hole. Without `at`/`onto` a joint takes `count: Count` (default 1). Fix every `part x[N]: ScrewJoint(...)` example (language.md 1, stdlib.md 3, geometry.md 1, README).
- G2: pattern-datum idiom (host declares `datum site` at the pattern centre, the clamped part is placed `on rail.site`); fix the geometry.md 1 example so it holds, and show a loosened tolerance flipping it to C002.
- G3: ScrewJoint exports `float: Length` and takes `locating: Bool = false`; a part placed on its host's pattern datum through a non-locating joint gets an implicit `[+-float]` on x and y of that placement (one source-variable pair per joint). New lint G005 bolted-float-unlocated (warning): a check tighter than the float reads through such a placement.
- G4: builtins `radial(p: Point3) -> Length`, `coaxial(a: Datum, b: Datum, allowance, over: Length)` (radius zone; diameter form is 2 * radial), `parallel(a, b, allowance, over)`, `angle_between(a, b) -> Angle`; type `Datum`; quantities.md 5.4: `x ^ 2` and `x * x` of the same affine form use a square-aware interval (never negative).
- G5: `Vec2(x, y)`/`Vec3`; array + Vec shifts every element, array + Point is G001; `Point3(...) on D` is the literal typing form for both point types, `p in D` is re-expression only; `in` maps over arrays; `aligned` and ScrewJoint convert both sides to `onto`'s datum and measure in its xy plane; `rect_pattern(nx, ny, dx, dy, rotation = 0deg)` with dx/dy pitches, ordered row by row, x fastest, from (-,-) to (+,+); precedence puts `in` between `..` and `as`; `IDENT in` starts a bound only when the right side is a range.
- G6: `place PART[i].d on EXPR for i in 0..count(PART)` (Count range form); `D.at(point)` offsets a datum to a point; G006 double-placement (error, fixed), G007 unplaced-instance (warning).
- G7: placement op arguments are members with path `Assembly/part.place.<op index>.<axis>` (for-placements: `Assembly/part[i].place...`); this supersedes the shorter `Assembly/<part>.place.x` in the C5 ruling. Pattern generators (`rect_pattern`, `circle_pattern`) are values with named members (`holes.pitch_x`, `holes.pitch_y`, `holes.radius`, `holes.start`, `holes.rotation`) which bind; derived coordinates are analysis-only unless the points are hand-listed. Bindable placement forms: offset terms -> mate distance; non-90deg rotate -> angle mate; flip and exact 90deg rotations are verified-only (read reports a drift note, never a push); a for-placement over a pattern binds to the native component pattern's generator.
- G8: locator kind `frame` (SW coordinate-system or plane feature); a datum binds to it, its offsets to the plane's dimensions; R007 compares a sketch's plane reference with it.
- G9: an interface may relate its datums by bound (`shaft.z == mount.z` style; I001 per implementer); re-typing `motor.mount_holes as Point2 on motor_face` is valid only where the model has both the part and its placement, else G003.
- G10: Datum and Placement carry `variants?` like Member; one `Op = offset | rotate | flip | at` shared by both; composed transform derived, not stored; drop `Datum.exact` (derived from ops).
- G11: reserved keywords add `datum place origin`; a member named `origin` is an error; the 3.1 class table lists `datum` for all classes and `place` for assemblies (S001 applies to datum offsets in an ots); add `and or not` to expressions; G003 becomes fixed.
- G12: write the allowance formulas explicitly (`(min(clearance_hole) - max(major)) / 2`, floating = sum of both halves; clearance_hole nominal; pairing by index); toleranced angles make coordinates conservative, exactness only for untoleranced multiples of 90deg; per-coordinate tolerance after a pattern vs tolerance on the generator pitch; `flip(x)` is sugar for `rotate(x = 180deg)`; `place A on B` makes frames coincide, so face-to-face mating needs a flip.
